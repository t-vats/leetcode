# 940. Distinct Subsequences II

## Problem Statement

Given a string `s`, return the number of distinct non-empty subsequences of `s`.

A subsequence is formed by deleting zero or more characters from `s` without changing the order of the remaining characters. Different selections of indices that produce the same string count only once.

Return the answer modulo `1_000_000_007`.

## Example 1

Input: `s = "abc"`  
Output: `7`

Explanation: The distinct non-empty subsequences are `a`, `b`, `c`, `ab`, `ac`, `bc`, and `abc`.

## Example 2

Input: `s = "aba"`  
Output: `6`

Explanation: The distinct non-empty subsequences are `a`, `b`, `ab`, `aa`, `ba`, and `aba`.

## Example 3

Input: `s = "aaa"`  
Output: `3`

Explanation: The distinct non-empty subsequences are `a`, `aa`, and `aaa`.

## Constraints

- `1 <= s.length <= 1000`
- `s` consists of lowercase English letters.

## Approach 1: Memoized Recursion

At each position, choose the next character of the subsequence. To avoid counting the same subsequence multiple times, for every letter from `a` to `z`, choose only its first occurrence at or after the current position.

Let `countFrom(index)` represent the number of distinct non-empty subsequences that can be formed using characters from `s[index..]`.

For every letter:

1. Find its first occurrence at or after `index`.
2. Count the subsequence containing that letter by adding `1`.
3. Add all subsequences that can be formed after that occurrence.
4. Store the result for `index` in a memo array.

The first-occurrence rule ensures that equivalent subsequences are counted only once.

### Java Solution

```java
import java.util.Arrays;

class Solution {
    private static final int MOD = 1_000_000_007;

    public int distinctSubseqII(String s) {
        int[] memo = new int[s.length() + 1];
        Arrays.fill(memo, -1);
        return countFrom(0, s, memo);
    }

    private int countFrom(int index, String s, int[] memo) {
        if (index == s.length()) {
            return 0;
        }

        if (memo[index] != -1) {
            return memo[index];
        }

        long total = 0;

        for (char character = 'a'; character <= 'z'; character++) {
            int firstPosition = s.indexOf(character, index);

            if (firstPosition != -1) {
                total += 1 + countFrom(firstPosition + 1, s, memo);
                total %= MOD;
            }
        }

        memo[index] = (int) total;
        return memo[index];
    }
}
```

## Approach 2: Last-Occurrence Dynamic Programming

Let `dp[i]` be the number of distinct subsequences, including the empty subsequence, that can be formed using the first `i` characters of `s`.

When adding a new character, every existing subsequence can either skip it or append it. This appears to double the count. However, if the character appeared before, appending it to subsequences from before its previous occurrence creates duplicates.

For a character with previous occurrence at position `last`, remove the duplicate subsequences counted before that occurrence:

`dp[i] = 2 * dp[i - 1] - dp[last - 1]`

If the character has not appeared before:

`dp[i] = 2 * dp[i - 1]`

The answer excludes the empty subsequence, so return `dp[s.length()] - 1`.

### Java Solution

```java
class Solution {
    private static final int MOD = 1_000_000_007;

    public int distinctSubseqII(String s) {
        long[] dp = new long[s.length() + 1];
        int[] lastOccurrence = new int[26];

        dp[0] = 1;

        for (int index = 1; index <= s.length(); index++) {
            int character = s.charAt(index - 1) - 'a';
            dp[index] = (2 * dp[index - 1]) % MOD;

            if (lastOccurrence[character] > 0) {
                dp[index] = (dp[index] - dp[lastOccurrence[character] - 1] + MOD) % MOD;
            }

            lastOccurrence[character] = index;
        }

        return (int) ((dp[s.length()] - 1 + MOD) % MOD);
    }
}
```

## Complexity

- Memoized recursion:
  - Time: `O(26 * n^2)` in the worst case because each state may search for 26 characters.
  - Space: `O(n)` for the memo array and recursion stack.
- Last-occurrence dynamic programming:
  - Time: `O(n)`.
  - Space: `O(n)` for the DP array and last-occurrence table.

## Why This Works

The memoized solution chooses a unique first occurrence for every possible next character, preventing duplicate subsequences from being generated. The last-occurrence DP solution counts all ways to extend existing subsequences and subtracts exactly the subsequences duplicated by a repeated character. Both approaches count every distinct non-empty subsequence exactly once.
