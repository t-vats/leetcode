# 115. Distinct Subsequences

## Problem Statement

Given two strings `s` and `t`, return the number of distinct subsequences of `s` that equal `t`.

A subsequence is formed by deleting zero or more characters from `s` without changing the order of the remaining characters. Different selections of indices count as different subsequences, even when they produce the same characters.

The test cases are generated so that the answer fits in a 32-bit signed integer.

## Example 1

Input: `s = "rabbbit"`, `t = "rabbit"`  
Output: `3`

Explanation: There are three different ways to delete one of the three `b` characters from `s` to form `rabbit`.

## Example 2

Input: `s = "babgbag"`, `t = "bag"`  
Output: `5`

## Constraints

- `1 <= s.length, t.length <= 1000`
- `s` and `t` consist of English letters.

## Approach 1: Memoization

Define `count(sourceIndex, targetIndex)` as the number of ways to form the suffix `t[targetIndex..]` using the suffix `s[sourceIndex..]`.

For each state, there are two choices:

- Skip `s[sourceIndex]` and move to the next character in `s`.
- If `s[sourceIndex]` matches `t[targetIndex]`, use it and move both pointers forward.

The recurrence is:

`count(i, j) = count(i + 1, j) + count(i + 1, j + 1)` when `s[i] == t[j]`

If the characters do not match, the current source character must be skipped:

`count(i, j) = count(i + 1, j)`

Memoization stores each `(sourceIndex, targetIndex)` result so that overlapping subproblems are solved only once.

### Base Cases

- If `targetIndex == t.length()`, the whole target has been formed, so return `1`.
- If `sourceIndex == s.length()` before the target is complete, return `0`.

### Java Solution

```java
import java.util.Arrays;

class Solution {
	public int numDistinct(String s, String t) {
		int[][] memo = new int[s.length()][t.length()];

		for (int sourceIndex = 0; sourceIndex < s.length(); sourceIndex++) {
			Arrays.fill(memo[sourceIndex], -1);
		}

		return countSubsequences(0, 0, s, t, memo);
	}

	private int countSubsequences(
			int sourceIndex, int targetIndex, String s, String t, int[][] memo) {
		if (targetIndex == t.length()) {
			return 1;
		}

		if (sourceIndex == s.length()) {
			return 0;
		}

		if (memo[sourceIndex][targetIndex] != -1) {
			return memo[sourceIndex][targetIndex];
		}

		int count = countSubsequences(sourceIndex + 1, targetIndex, s, t, memo);

		if (s.charAt(sourceIndex) == t.charAt(targetIndex)) {
			count += countSubsequences(sourceIndex + 1, targetIndex + 1, s, t, memo);
		}

		memo[sourceIndex][targetIndex] = count;
		return count;
	}
}
```

## Approach 2: One-Dimensional Dynamic Programming

Use dynamic programming while scanning `s` from left to right.

Let `dp[j]` be the number of ways to form the first `j` characters of `t` using the characters processed from `s` so far.

Initially, `dp[0] = 1` because there is exactly one way to form an empty string: select no characters. Every other `dp[j]` starts at `0`.

For each character in `s`:

1. Traverse `t` from right to left.
2. If the characters match, add the number of ways to form the previous prefix:

   `dp[j] = dp[j] + dp[j - 1]`

3. Traverse backwards so that each character from `s` is used at most once in the current update.

The final value `dp[t.length()]` is the number of distinct subsequences equal to `t`.

### Java Solution

```java
class Solution {
	public int numDistinct(String s, String t) {
		int[] dp = new int[t.length() + 1];
		dp[0] = 1;

		for (int sourceIndex = 0; sourceIndex < s.length(); sourceIndex++) {
			for (int targetIndex = t.length(); targetIndex >= 1; targetIndex--) {
				if (s.charAt(sourceIndex) == t.charAt(targetIndex - 1)) {
					dp[targetIndex] += dp[targetIndex - 1];
				}
			}
		}

		return dp[t.length()];
	}
}
```

## Complexity

- Memoization:
	- Time: `O(s.length * t.length)`
	- Space: `O(s.length * t.length)` for the memo table and recursion stack.
- One-dimensional dynamic programming:
	- Time: `O(s.length * t.length)`
	- Space: `O(t.length)`.

## Why This Works

For memoization, every state represents a unique pair of positions in `s` and `t`, and the recurrence considers every valid choice exactly once. For the one-dimensional solution, every matching pair of characters extends the ways to form the previous target prefix, while the existing count preserves ways that skip the current source character. Processing the target from right to left prevents one source character from being reused during the same update.
