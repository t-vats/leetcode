# 3871. Count Commas in Range II

## Problem Statement

You are given an integer `n`.

Return the total number of commas used when writing every integer from `1` through `n` in standard number formatting.

In standard formatting, a comma is inserted after every three digits from the right. Numbers with fewer than four digits contain no commas.

## Example 1

Input: `n = 1002`  
Output: `3`

Explanation: The numbers `1,000`, `1,001`, and `1,002` each contain one comma, giving a total of `3`.

## Example 2

Input: `n = 998`  
Output: `0`

Explanation: Every number from `1` through `998` has fewer than four digits, so no commas are used.

## Constraints

- `1 <= n <= 10^15`

## Key Idea

Count the contribution of each possible comma position separately.

- Every number from `1,000` onward has a comma after the first three digits.
- Every number from `1,000,000` onward has a second comma.
- Every number from `1,000,000,000` onward has a third comma.
- The pattern continues for every power of `1,000`.

For a comma threshold `place`, the number of integers from `place` through `n` is:

`n - place + 1`

Therefore, add this value for every threshold `place <= n`, starting with `1,000` and multiplying the threshold by `1,000` each time.

This avoids iterating through all numbers from `1` to `n`, which is necessary because `n` can be as large as `10^15`.

## Java Solution

```java
class Solution {
	public long countCommas(long n) {
		long total = 0;

		for (long place = 1_000L; place <= n; place *= 1_000L) {
			total += n - place + 1;
		}

		return total;
	}
}
```

| `1002` | `3` | Pass |

| `1000000000000000` | `3998998998999005` | Pass |

## Complexity

- Time: `O(log_1000(n))`, because the threshold is multiplied by `1,000` each iteration.
- Space: `O(1)`.

## Why This Works

Each comma position contributes independently. The first comma appears in every number at least `1,000`, the second appears in every number at least `1,000,000`, and each later comma follows the same pattern. Summing `n - place + 1` over all valid thresholds counts every comma exactly once.
